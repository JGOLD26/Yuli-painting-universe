# 🌟 Yuli's Universe

A fun, browser-based 2D platformer game inspired by **Yuli's beautiful city painting** — a crayon drawing of a city skyline with buildings, clouds, a sun, trees, and more!

## 🎮 How to Play

1. **Open `index.html`** in any modern browser (Chrome, Firefox, Safari, Edge)
2. Click the **▶ Play!** button on the start screen
3. Explore the city and collect all the ⭐ stars!

### Controls

| Action | Keys |
|--------|------|
| Move Left | ← Arrow or **A** |
| Move Right | → Arrow or **D** |
| Jump | ↑ Arrow, **W**, or **Space** |

## ✨ Features

- 🏙️ **City Skyline** — Buildings of varying heights drawn in a blue/indigo crayon style, complete with glowing windows
- ☁️ **Animated Clouds** — Fluffy clouds drifting across the sky with parallax scrolling effect
- ☀️ **Spinning Sun** — Animated sun with rays in the upper-right corner, just like Yuli's painting
- 🌲 **Evergreen Trees** — Cute trees scattered between the buildings
- 🧑‍🎤 **Cute Avatar** — A friendly character with idle bobbing and walk animations
- ⭐ **Collectible Stars** — 20 stars scattered around the world at various heights — some require jumping!
- 🌍 **Wide Scrolling World** — The city is bigger than the screen; explore by walking left and right
- 💨 **Dust Effects** — Small dust puffs when the avatar walks
- ✨ **Sparkle Effects** — Colorful sparkles burst when you collect a star
- 📱 **Responsive** — Adapts to different screen sizes

## 🎨 Inspiration

This game was lovingly created to bring **Yuli's hand-drawn crayon city painting** to life as an interactive world. The color palette (blue/indigo buildings, warm sun, fluffy clouds) and art style (sketchy outlines, crayon feel) are directly inspired by her original artwork.

## 🚀 Getting Started

No installation or build tools needed — it's a single HTML file!

```bash
# Just open the file in your browser:
open index.html
# or double-click index.html in your file explorer
```

## 🛠️ Technical Details

- **Single file**: All HTML, CSS, and JavaScript in `index.html`
- **No dependencies**: Everything drawn with the HTML5 Canvas API
- **No external images**: All graphics are programmatically drawn
- Works in all modern browsers
